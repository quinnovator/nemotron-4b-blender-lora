# Blender Scene resources server

A NeMo Gym environment where the model writes a Blender 5.2 `bpy` script that builds
a scene described in plain English ("stack a 0.69 m cube on a 1.26 m cube at
x = -2.09, y = 1.31"). `verify()` runs the script and scores the scene it builds.

## How verification works

1. The fenced Python block is pulled out of the reply (`envlib.reward.extract_code`).
2. The script goes to the host-side sandbox broker (`sandbox/broker.py`), which runs it
   in a throwaway Docker container: no network, read-only filesystem, 2 GB, 1 CPU,
   128 pids, non-root, 40 s limit. A second, clean Blender measures every mesh from the
   saved scene, so nothing the script does can write the measurements itself.
3. The task's geometric checks (name, size, resting on the ground, position, contact;
   3 cm tolerance) score the measured scene:
   `0.1 if it runs + 0.5 x share of checks passed + 0.4 if all pass`.

The broker exists so the training container never holds the Docker socket. Start it on
the host with `python -m sandbox.broker` (stages/train.py does this automatically).
The server finds `envlib/` through `repo_root` in its config, or `$BLENDER_LORA_ROOT`,
which `nemo/docker_run.sh` sets.

Extra numeric fields in each verify response (`full_pass`, `ran`, `check_fraction`) show
up as per-agent metrics in NeMo RL.

## Data

`python -m gym_env.build_data runs/<run>` writes `data/{train,eval_id,eval_transfer}.jsonl`
from a run's task splits (stages/train.py runs it before training). Only `example.jsonl`
is checked in. Rows carry the chat input, `verifier_metadata.task` and
`agent_ref: blender_scene_simple_agent`. Training uses the `stack` and `next_to`
templates; `between` is held out for evaluation.

## Tests

```sh
nemo/docker_run.sh 'cd 3rdparty/Gym-workspace/Gym && ng_test +entrypoint=resources_servers/blender_scene'
```

That runs them inside the NeMo RL container, with this directory mounted at
`resources_servers/blender_scene`. The tests stub the
broker and score scene states captured from the real sandbox.
